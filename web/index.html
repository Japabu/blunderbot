Blunderbot uses Chess.com’s published loss bands with Lichess’s public conversion from engine scores to winning chances. It does not reproduce Chess.com’s private rating-adjusted model.

Chess.com also rewards pivotal “Great” moves and sound sacrifices as “Brilliant.” Those need extra tactical analysis; this version does not guess either label. The old fast-good-move category is removed.
